# Product Captures contributor instructions

For C#/.NET work, read Microsoft's complete maintained [C# coding conventions](https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals/coding-style/coding-conventions?accept=text/markdown), including its examples. An unchanged [official Markdown snapshot](docs/standards/csharp-dotnet.md) is available offline; [source, licenses and refresh instructions](docs/standards/NOTICE.md) are separate. Use the upstream document as the conventions source; do not replace it with a project checklist or generated summary. Respect explicit repository constraints and supported language versions. Use the official `csharp-refactoring` skill when available for behavior-preserving structural cleanup.

Preserve public JSON/API/defaults/errors, rendering string values, output ownership, explicit screenshot reuse, publication guards and process cancellation/cleanup. Keep the Node adapter and approved image bytes unchanged during readability work. Verify all three project format checks/builds, core/adapter contracts, host contracts, composition parity and a fresh generic browser smoke before release. Release names are exactly their version tags.
