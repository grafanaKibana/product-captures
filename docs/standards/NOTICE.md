# Official Microsoft C# coding conventions

The conventions are maintained by Microsoft in [dotnet/docs](https://github.com/dotnet/docs/blob/main/docs/csharp/fundamentals/coding-style/coding-conventions.md) and published on [Microsoft Learn](https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals/coding-style/coding-conventions).

`csharp-dotnet.md` is an unchanged copy of Microsoft's complete Markdown export, including the code examples and original scope statements. No project-specific rules or authored adaptations are added. Its front matter records the canonical URL and published source revision. Relative further-reading links are preserved from the official export; use the online article to follow them.

Documentation retains Microsoft's [CC BY 4.0 license](LICENSE); code examples retain Microsoft's [MIT license](LICENSE-CODE). These files are not relicensed under the toolkit's MIT grant. Microsoft maintains the guidance; this repository only keeps an offline snapshot. No endorsement is implied.

To refresh the snapshot from the repository root:

```sh
curl --fail --location 'https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals/coding-style/coding-conventions?accept=text/markdown' --output docs/standards/csharp-dotnet.md
```

Review upstream changes before committing the refreshed copy. Update the accompanying license files from `dotnet/docs` if their terms change. No custom generator or standards framework is required.
